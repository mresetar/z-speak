3592 is the cartridge format used by IBM's TS1100 drives, the successor to the 3480, 3490 and 3590 lines whose device-type names still appear in JCL `UNIT` parameters and esoteric names. Each drive generation raised capacity on the same cartridge shape; the TS1170 writes 50 TB uncompressed on a single cartridge. Drives encrypt and compress in hardware and live in automated libraries such as the TS4500.

On a current mainframe, applications rarely write to these drives directly. Jobs write to **virtual tape** — a TS7700 that looks like tape drives but is a disk cache — and the TS7700 migrates volumes to 3592 cartridges behind the scenes, stacking many logical volumes on each.

It is a different thing from **LTO**, the open midrange format. The two share technology, but 3592 is the one with the enterprise drive features and the one the mainframe tape ecosystem is built around.
