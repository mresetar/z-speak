When a z/OS storage administrator says "the disk", they mean a storage system like this one. A DS8000 is a pair of servers with redundant everything, all-flash capacity, and FICON ports to the mainframe. On top of that capacity it *emulates* the devices z/OS expects: 3390 volumes in CKD format, grouped into **logical control units** of up to 256 addresses each. The same box can serve fixed-block volumes to Linux and distributed systems.

The value is in the functions built for z/OS, several of which have their own entries here: **PAV** aliases for concurrent I/O to a volume, **zHPF** and **zHyperLink** for speed, **FlashCopy** for point-in-time copies, **Metro Mirror** and **Global Mirror** for replication, **Safeguarded Copy** against logical corruption, encryption of data at rest, and tiering of inactive data to cloud object storage. Most are licensed features, so what a given installation can do depends on what was bought.

It is administered through a graphical interface or the DS command-line interface, and its copy functions are usually orchestrated by Copy Services Manager or GDPS.

IBM is not the only supplier. Hitachi and Dell sell systems that emulate the same devices and many of the same functions; z/OS skills carry over directly, while product names and the support for the newest features differ.
