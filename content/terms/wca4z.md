The capability that earns its keep is not code generation — it is **explanation and discovery**. It analyses an application to produce a blueprint of programs, data and their relationships, explains a COBOL, PL/I, REXX, Assembler or JCL routine in plain language, and does impact analysis before a change. That addresses the actual bottleneck on most estates: nobody knows what the code does any more.

Beyond that it does automated refactoring, code generation, and optional transformation of COBOL to Java. Recent releases add an agentic workflow and MCP-enabled tools so the same capabilities can be driven from an AI coding agent.

Treat generated or transformed code as a draft to be reviewed and tested, exactly as you would from any assistant.
