Log on to a mainframe (a pretend one)

This page plays both parts: a 3270 terminal emulator and a small z/OS host behind it. Connect, log on to TSO, create and edit data sets in ISPF, run a REXX exec, compile a COBOL program, submit batch jobs and read their output. Nothing leaves your browser, and you can't break anything.

          Keyboard map
          

            
3270 keyOn your keyboardWhat it does

            
EnterReturnSends the screen to the host. Nothing reaches z/OS until you press it.

            
PF1–PF12F1–F12 (Shift = PF13–24)Program function keys. F3 = back/exit, F5/F6 = repeat find/change in the editor, F7/F8 = scroll up/down, F12 = cancel. Mac: use the buttons, fn, or PgUp/PgDn for F7/F8.

            
ClearEscWipes the screen and tells the host.

            
PA1 / PA2Alt+1 / Alt+2Attention (interrupt) / reshow the screen.

            
Tab / Back-tabTab / Shift+TabJump between input fields. You can only type in input fields.

            
Erase EOFEndBlanks the rest of the field. Use it before retyping.

            
InsertInsert or Ctrl+IOvertype is the default, like a real 3270.

            
ResetAlt+RClears an X error in the status line.

            
New lineShift+ReturnCursor to the first field on the next line.
